# LISTIXAAR ONLINE V10

## Objectif atteint
V10 est la version de préparation au **véritable déploiement public**.

Le paiement marchand n'est pas encore activé, conformément à la décision :
1. mettre LISTIXAAR complètement en ligne ;
2. tester et valider le programme ;
3. ensuite connecter le prestataire de paiement et le code marchand.

## À faire maintenant
Suivre `deploy/README.md` et `deploy/prelaunch_checklist.md`.

### Important
V10 n'est pas une mise en ligne automatique : il faut encore un hébergeur, un domaine et une base PostgreSQL de production. Ces accès ne sont pas fournis automatiquement par le ZIP.

## Étape après V10
Déploiement réel sur le serveur choisi, puis validation publique. Après validation : intégration du paiement.
